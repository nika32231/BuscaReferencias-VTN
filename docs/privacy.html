Política de privacidad

Esta página explica qué datos se usan en BuscaReferencias VTN, cómo se procesan y qué opciones tienes.

Resumen rápido

Versión breve y clara.

BuscaReferencias VTN no está pensada para recopilar datos personales sensibles de forma deliberada. La app web solo guarda en tu navegador configuraciones básicas como la URL del backend y la parte anatómica activa.

Cuando realizas búsquedas, el frontend envía al backend los términos generados desde tu dibujo y, si existe, la información de pose necesaria para calcular similitud. Ese intercambio se usa únicamente para mostrar referencias.

Datos que se utilizan

Solo lo necesario para que funcione la búsqueda.

  • Preferencias locales: URL del backend, parte anatómica activa y estado de la interfaz.
  • Términos de búsqueda: palabras generadas desde el canvas para encontrar referencias reales.
  • Datos técnicos temporales: caché de miniaturas, sesión de búsqueda y resultados mostrados.
  • Metadatos de imágenes: miniatura, URL original, autor, página de origen y similitud.

Cómo se procesan las imágenes

Flujo principal de la app.

  1. El usuario dibuja una pose en el canvas.
  2. La interfaz genera términos de búsqueda relacionados con anatomía, movimiento y postura.
  3. El backend consulta proveedores online, como Pexels, y descarga miniaturas temporales.
  4. MediaPipe analiza las imágenes para obtener embeddings, ángulos y similitud estructural.
  5. La galería muestra miniaturas reales, porcentaje de similitud y enlace a la página original.

Cookies y almacenamiento local

La web usa almacenamiento del navegador.

La versión web puede usar localStorage para recordar la URL del backend y la parte anatómica activa. No utilizamos cookies de seguimiento ni perfiles publicitarios desde este frontend.

Servicios de terceros

Dependencias externas usadas para buscar referencias.

La app puede consultar servicios externos como Pexels y otros proveedores configurados en el backend. Cada proveedor tiene su propia política de privacidad y términos de uso.

Cuando haces clic en una miniatura, se abre la página original del proveedor para que puedas revisar la fuente.

Retención y caché

Las miniaturas son temporales.

Las imágenes descargadas para una búsqueda se almacenan solo de forma temporal en la sesión actual, con el objetivo de acelerar la galería y el análisis por MediaPipe.

Al iniciar una nueva búsqueda, la caché temporal se limpia para evitar acumulación innecesaria.

Tus opciones

Control básico desde el navegador.

  • Puedes borrar el almacenamiento local del navegador para resetear la configuración.
  • Puedes cambiar la URL del backend en cualquier momento.
  • Puedes dejar de usar el servicio cerrando la página o desconectando el backend.
